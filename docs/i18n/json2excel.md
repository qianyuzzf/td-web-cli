# 多语言 JSON 转 Excel 工具

该工具用于将多语言 JSON 翻译文件合并生成一个 Excel 文件，方便翻译校对和统一管理。支持自动读取配置文件，识别默认语言和语言名称，灵活处理多语言目录结构。

---

## 主要功能

1. **配置文件加载**
   - 读取本地 `setting.json` 配置，获取默认语言、语言映射名称和语言长代码等信息。
   - 校验配置完整性，保证后续处理正确。

2. **多语言 JSON 文件读取**
   - 用户通过命令行输入存放多语言 JSON 文件的根目录。
   - 根目录下每个子目录代表一个语言（语言 key），每个语言目录下需包含 `translate.json` 文件。
   - 自动扫描所有语言目录，加载对应的 JSON 翻译内容。

3. **语言有效性校验**
   - 跳过不存在或缺失 `translate.json` 的语言目录，输出警告。
   - 若未找到任何有效语言文件，程序终止。

4. **默认语言处理**
   - 从配置中读取默认语言 key。
   - 若默认语言未在已加载语言中，使用所有语言词条 key 的并集作为基准。

5. **词条 Key 合并**
   - 收集所有语言 JSON 文件中的词条 key 的并集，确保 Excel 中包含所有词条。
   - 对所有 key 进行排序，保证输出的顺序统一。

6. **构建 Excel 表头**
   - 第一列为默认语言的名称（优先使用配置中的语言名称列表的第一个名称）。
   - 后续列为其他语言的名称，均从配置中获取语言名称映射，若无则使用语言 key。

7. **生成 Excel 内容**
   - 每行对应一个词条 key。
   - 第一列显示词条 key（默认语言词条）。
   - 后续列显示对应语言的翻译内容，若无对应翻译则留空。

8. **导出 Excel 文件**
   - 生成 Excel 文件，文件名格式为 `lang_merged_时间戳.xlsx`，保存在输入的根目录下。
   - Excel 工作表命名为 `Translations`。

9. **日志与异常处理**
   - 详细输出加载语言、词条数量、警告和错误信息。
   - 读取或解析失败时记录错误并安全退出。
   - 程序异常时记录日志并退出。

---

## 使用说明

1. 准备好多语言 JSON 文件，目录结构如下示例：

   ```
   rootDir/
     en/
       translate.json
     cn/
       translate.json
     fr/
       translate.json
   ```

2. 配置好 `setting.json`，包含 `defaultKey`、`langs` 和 `longCodes`。

3. 运行工具，输入多语言 JSON 文件根目录路径。

4. 程序自动加载所有语言 JSON，合并词条，生成 Excel 文件。

5. 结果文件保存在根目录，方便查看和翻译。

---

## 代码结构简述

- **loadConfig(configPath: string): I18nConfig**  
  读取并校验配置文件格式，返回国际化配置对象。

- **json2excel(program: Command)**  
  主流程函数，交互输入目录，加载多语言 JSON，合并词条，生成 Excel 文件。

---

## 备注

- 默认语言词条作为 Excel 第一列，方便对照和校验。
- 支持自动跳过缺失或错误的语言目录，保证程序稳定执行。
- 生成的 Excel 文件便于翻译人员进行集中管理和修改。
- 配置文件中语言名称映射提升 Excel 表头可读性。
