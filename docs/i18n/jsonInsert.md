# 多语言 JSON 文件插入工具

该工具用于从指定的**待插入 JSON 目录**中提取**用户指定的键**，批量插入到**源 JSON 目录**具有相同结构的文件中。当目标键已存在且值不同时，支持一键覆盖或逐键手动选择，方便多语言翻译内容的精准同步。

---

## 主要功能

1. **按需键插入**
   - 用户指定一组 JSON 键（多个键用英文逗号分隔）。
   - 工具自动扫描源目录与插入目录，在相同的语言子文件夹（如 `cn`、`en`）和相同的 JSON 文件内，仅插入指定的键。

2. **冲突策略可配**
   - 当目标键已存在且值不同时，提供两种处理方式：
     - **直接覆盖**：始终使用插入文件中的值，无需人工干预。
     - **手动选择**：在命令行交互提示中逐键选择保留源值还是使用插入值。

3. **多语言目录结构适配**
   - 源目录与插入目录均采用语言子文件夹结构（如 `cn/translate.json`）。
   - 自动识别两个目录下共同存在的语言子文件夹和 JSON 文件，确保操作范围准确。

4. **安全读写**
   - JSON 文件解析失败或不存在时返回空对象，避免程序中断。
   - 写入时自动创建父目录，格式化缩进输出，保持文件可读性。

5. **详细日志与反馈**
   - 输出源目录、插入目录、待插入键列表、冲突处理策略。
   - 记录每个文件的原有键数、插入后键数。
   - 对缺失的键、跳过的情况进行警告提示。

6. **异常捕获与安全退出**
   - 全局异常捕获，错误信息记录日志后退出，防止数据部分写入。

## 使用说明

1. 准备两个多语言 JSON 根目录，目录结构示例：

```
  srcDir/ # 源目录（将被修改）
    cn/
      translate.json
    en/
      translate.json

  insertDir/ # 待插入目录（仅读取，不修改）
    cn/
      translate.json
    en/
      translate.json
```

2. 运行工具，按提示依次输入：

- **源 JSON 文件夹路径**：最终修改的目标目录。
- **待插入 JSON 文件夹路径**：提供待插入键值对的目录。
- **需要插入的 JSON key**：例如 `greeting, farewell, new_key`。
- **冲突处理策略**：
  - `直接覆盖（始终使用插入文件值）`
  - `手动选择（针对每个冲突键提示）`

3. 程序自动扫描共同的顶层语言文件夹（如 `cn`、`en`），并在每个语言文件夹下找出共同的 JSON 文件。

4. 对每个文件执行键插入：

- 若指定的键在**待插入文件**中不存在 → 跳过并警告。
- 若指定的键在**源文件**中不存在 → 直接新增。
- 若指定的键在源文件中已存在且值相同 → 跳过。
- 若已存在且值不同 → 根据所选策略处理（自动覆盖或手动选择）。

5. 所有更改直接写回**源目录**对应文件，插入目录保持不变。

## 代码结构简述

- **readJsonFile(filePath: string): Record<string, any>**  
  安全读取 JSON 文件，异常时返回空对象。

- **writeJsonFile(filePath: string, data: Record<string, any>)**  
  格式化写入 JSON 文件，自动创建目录结构。

- **getJsonFilesInLangDir(dirPath: string): string[]**  
  返回指定目录下所有 `.json` 文件名称列表。

- **insertKeysIntoObject(baseObj, insertObj, keys, langKey, strategy)**  
  核心插入逻辑：根据冲突策略将指定键从插入对象合并到源对象。

- **jsonInsert(program: Command)**  
  主流程函数：交互式输入参数，匹配语言文件夹与 JSON 文件，调用插入逻辑完成批量操作。

---

## 备注

- 本工具**仅修改源目录**，待插入目录仅作为数据来源，不会发生任何改变。
- 若两个目录中缺少共同的语言文件夹或 JSON 文件，对应部分将被跳过，不影响其他部分。
- 建议在操作前对源目录进行备份，以便在意外情况下恢复。
- 日志提供详细的键变化数量，便于快速核对插入结果。
- 手动冲突选择模式适合需要精确控制翻译内容的场景；直接覆盖模式适合批量同步标准化键值。
