# 多语言 JSON 文件合并工具

该工具用于合并两个多语言 JSON 文件夹中相同语言子文件夹下的 JSON 文件，支持键冲突时交互式选择保留值，方便多语言翻译内容的整合与管理。

---

## 主要功能

1. **JSON 文件读取与写入**
   - 安全读取指定路径的 JSON 文件，格式错误或文件不存在时返回空对象。
   - 将合并后的 JSON 对象格式化写入文件，自动创建目录。

2. **键冲突交互处理**
   - 合并两个 JSON 对象时，若发现相同键但对应值不同，提示用户选择保留源文件值还是合并文件值。
   - 支持命令行交互式选择，保证合并结果符合预期。

3. **多语言目录支持**
   - 支持两个多语言 JSON 根目录，目录结构为语言子文件夹（如 `cn`、`en` 等）。
   - 自动识别两个目录下的语言子文件夹，找出共同存在的语言进行合并。

4. **同语言文件合并**
   - 在相同语言子文件夹内，找出共同存在的 JSON 文件进行逐个合并。
   - 跳过不存在的语言文件夹或 JSON 文件，保证流程稳定。

5. **详细日志输出**
   - 记录源目录和合并目录路径。
   - 输出发现的共同语言文件夹及共同 JSON 文件列表。
   - 记录每个文件合并前后的键数量。
   - 提示合并过程中的警告和异常。

6. **异常捕获与安全退出**
   - 捕获异常并记录日志。
   - 出现异常时打印错误信息并退出程序，避免数据损坏。

---

## 使用说明

1. 准备两个多语言 JSON 根目录，目录结构示例：

   ```
   srcDir/
     cn/
       translate.json
     en/
       translate.json

   mergeDir/
     cn/
       translate.json
     en/
       translate.json
   ```

2. 运行工具，依次输入源 JSON 文件夹路径和待合并 JSON 文件夹路径。

3. 程序自动识别共同语言文件夹及共同 JSON 文件，逐个文件合并。

4. 当遇到相同键但值不同时，命令行交互提示选择保留哪个值。

5. 合并结果直接写回源目录对应文件。

---

## 代码结构简述

- **readJsonFile(filePath: string): Record<string, any>**  
  读取 JSON 文件内容，异常时返回空对象。

- **writeJsonFile(filePath: string, data: Record<string, any>)**  
  格式化写入 JSON 文件，自动创建目录。

- **mergeJsonObjects(baseObj, mergeObj, langKey): Promise<Record<string, any>>**  
  合并两个 JSON 对象，键冲突时交互选择保留值。

- **getJsonFilesInLangDir(dirPath: string): string[]**  
  获取指定语言目录下所有 JSON 文件名。

- **jsonMerge(program: Command)**  
  主流程函数，交互输入路径，识别语言文件夹和 JSON 文件，执行合并操作。

---

## 备注

- 交互式冲突解决确保合并结果符合用户需求，避免覆盖重要翻译内容。
- 仅合并两个目录中共同存在的语言文件夹和 JSON 文件，避免误操作。
- 日志详细，方便跟踪合并进度和排查问题。
- 合并操作直接修改源目录文件，请提前备份重要数据。
