# 图片压缩工具

该工具基于 `sharp` 库，实现对多种图片格式的压缩处理，支持多种压缩级别及自动缩放超大图片，方便用户在命令行交互中完成图片体积优化。

---

## 主要功能

1. **支持多种图片格式**
   - 支持 `.jpg`、`.jpeg`、`.png`、`.webp`、`.avif`、`.tiff`、`.gif` 等主流图片格式。
   - 读取 GIF、WebP 和多页 TIFF 时保留全部动画帧或页面，不会只输出第一帧。

2. **多级压缩选项**
   - 提供四个压缩级别选择：
     - 无损压缩：完全保留原始画质，体积减小较少。
     - 视觉无损压缩：肉眼几乎无差异，体积明显减小。
     - 有损压缩：轻微画质下降，体积大幅减小。
     - 高损压缩：画质明显下降，体积最小。

3. **自动缩放超大图片**
   - 可选择自动缩放宽度超过 2560px 的图片，缩小至 2560px，保持纵横比，防止图片过大。

4. **智能格式识别与参数调整**
   - 根据图片格式和压缩级别自动应用对应的压缩参数，兼顾画质和体积。
   - GIF 同样支持无损、视觉无损、有损和高损四档参数。

5. **交互式命令行体验**
   - 通过命令行交互输入图片路径。
   - 选择压缩级别。
   - 确认是否启用自动缩放。

6. **输出文件处理**
   - 压缩后的图片保存于原目录，文件名添加随机6位后缀，避免覆盖原文件。
   - 默认移除 EXIF、XMP、IPTC 等输入元数据，进一步减小体积并避免携带隐私信息。
   - 输出日志显示原始大小、压缩后大小及压缩率。

7. **异常捕获与日志**
   - 捕获处理过程中的异常，记录详细日志。
   - 出错时提示用户并安全退出。

---

## 使用说明

1. 运行程序后，输入需要压缩的图片文件路径（支持多种格式）。

2. 选择压缩级别，查看对应的压缩效果描述。

3. 选择是否自动缩放超大图片。

4. 程序完成压缩后，输出压缩文件路径及压缩率信息。

5. 压缩文件保存在原图片同目录，文件名带随机后缀，避免覆盖。

---

## 代码结构简述

- **generateShortSuffix(): string**  
  生成6位随机字符串，用于输出文件名后缀。

- **getOutputPath(inputPath: string): string**  
  生成输出文件路径，格式为原文件名 + 随机后缀 + 原扩展名。

- **createImageProcessor(input: string | Buffer): Sharp**：创建保留动画帧和多页内容的 Sharp 处理管线。

- **compressImage(program: Command)**  
  主流程函数，交互输入图片路径和压缩级别，执行压缩处理并保存文件。

- **压缩参数配置**  
  根据图片格式（JPEG、PNG、WebP、AVIF、TIFF、GIF）和压缩级别动态设置 sharp 参数。

- **自动缩放逻辑**  
  当用户同意且图片宽度超过 2560px 时，自动缩放图片宽度至 2560px。

---

## 备注

- 动画 GIF 会保留帧数和播放信息；有损档位可能减少颜色数量或提高帧间误差以缩小体积。
- 输出默认不保留图片元数据；需要保留元数据的场景应先另行备份原图。
- 压缩效果和体积大小依赖于图片内容和格式，选择合适的压缩级别可平衡质量与大小。
- 输出文件名带随机后缀，避免误覆盖原文件，便于版本管理。
- 适合需要批量或单张图片压缩优化的开发和设计场景。
