# 节假日查询与提醒工具

该工具用于获取指定年份的节假日数据，计算距离当前日期最近的几个节假日，并打印详细信息及温馨提示，方便用户及时了解假期安排。

---

## 主要功能

1. **节假日数据获取**
   - 默认请求当前年份的节假日 JSON 数据。
   - 当前年份不足三个未来假期时，自动补充下一年数据；下一年请求失败时仍展示当前可用结果。
   - 支持公共假期（public_holiday）和调休日（transfer_workday）两种类型。

2. **节假日合并与分组**
   - 对连续日期且名称相同的节假日进行合并，形成节日区间。
   - 按本地日期零点计算剩余天数，当天假期会被计入且剩余天数为 `0`。

3. **调休日匹配**
   - 识别节假日区间前后7天内的调休日，标记节假日是否包含调休。
   - 列出相关调休日日期。

4. **最近节假日筛选**
   - 返回距离今天最近的指定数量（默认3个）节假日汇总信息。

5. **终端彩色输出与提示**
   - 打印最近节假日名称（黄色加粗）、剩余天数（绿色）、放假日期（紫色）、调休日（红色）。
   - 根据最近节假日剩余天数打印不同风格的温馨提示和表情。

6. **异常捕获与日志**
   - 捕获异常，记录详细日志，保证程序稳定运行。
   - 出错时提示用户并安全退出。

---

## 使用说明

1. 运行程序后，自动请求当前年份的节假日数据；必要时继续请求下一年数据。

2. 程序计算并打印最近三个节假日的详细信息。

3. 根据最近节假日剩余天数，显示对应的鼓励或提醒文案。

4. 彩色终端输出提升可读性和用户体验。

---

## 代码结构简述

- **getNearestHolidays(data: HolidayData, count?: number, now?: Date): HolidaySummary[]**：计算并返回最近若干个节假日汇总信息，包含节日名称、剩余天数、放假日期及调休日。

- **printHolidayMessage(minDays: number): void**  
  根据最近节假日剩余天数，打印不同风格的节假日提醒文案和表情。

- **getHolidayTime(): Promise<void>**  
  主流程函数，获取节假日数据，计算并打印最近节假日详情及温馨提示。

---

## 备注

- 节假日日期和“今天”都归一化为本地时区午夜，确保当天假期不会被过滤。
- 调休日匹配范围为节假日区间前后7天，覆盖常见调休安排。
- 彩色输出兼容大多数终端，提升信息可视化效果。
- 适合个人或团队节假日提醒和计划安排。
